# techno-bibi

メガベンチャーで AI エージェント開発プロジェクトに参画しながら、個人事業「テクノビビ」としてアプリ・Web サービスの企画・開発・運営を行っています。

## 運営中のサービス

| サービス | 内容 | リンク |
| --- | --- | --- |
| **いこストック**（iOS） | SNS や Web で見つけた行きたい場所を保存し、リスト・地図で見返せるアプリ。複数人での共同プランニングにも対応。App Store 旅行カテゴリ 1 位・総合 11 位、公開初日に 1 万ダウンロード | [App Store](https://apps.apple.com/jp/app/id6791623306) / [ikostock.app](https://ikostock.app/) |
| **あさよむ テック** | エンジニア向けに英語圏のテックニュース・私信論文を日本語要約で毎朝配信 | [tech.asayomu.jp](https://tech.asayomu.jp/) |

## 公開リポジトリ

- [**master-llm**](https://github.com/technobibi/master-llm) — ローカル LLM（LM Studio）と Claude を組み合わせたオーケストレーションを、「Claude 単体」と同一タスク・同一指示で比較する評価ハーネス。精度・クラウドコスト・実時間の 3 軸で計測し、HumanEval / MBPP の取り込みとルーティング学習データの生成まで行う
- [**OSSMate**](https://github.com/technobibi/OSSMate) — OSS のトレンドと Good First Issue を一覧化する Web アプリ（Go + React）

## 取り組んでいる技術

- **AI エージェントのハーネス・ループ設計**: Issues駆動の Issue 起票 → TDD 実装 → 敵対的レビュー → リリースまでをエージェントが自走するループの設計と運用
- **ローカル LLM とクラウドモデルの使い分け**: 処理内容・データの扱い・応答速度・コストに応じたルーティングの研究と実装
- **検索・業務への AI 活用**: 文書や業務データのベクトル化と検索への組み込み
