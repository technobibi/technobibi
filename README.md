# techno-bibi

メガベンチャーで AI エージェント開発プロジェクトに参画しながら、個人事業「テクノビビ」として AI エージェントの研究と、アプリ・Web サービスの企画・開発・運営を行っています。

## 参画プロジェクト — エンジニアリングの自動化

AI エージェントがソフトウェア開発の工程を自走するための基盤を設計・実装しています。

- **ハーネス設計・ループ設計** — エージェントが判断・実行・検証・修正を反復するための実行基盤
- **CI/CD の自動マージゲート** — AI によるレビュー結果を合否判定に組み込み、マージ可否を自動で決める
- **デプロイ・マイグレーションの自動化** — スキーマ変更を含むリリースを、後方互換の検証を通したうえで適用する
- **脆弱性の自動修正パイプライン** — CVE の検知から修正パッチの生成、検証、デプロイまでを一続きで実行する

## 個人研究

- **ローカル LLM とクラウドモデルのルーティング** — 処理内容・データの扱い・応答速度・コストに応じて実行先を振り分ける。評価ハーネスを [master-llm](https://github.com/technobibi/master-llm) で公開しています
- **日本語命令の最適化** — 敬語や婉曲表現を含む指示、前提が省略された指示から、モデルが実行できる形へ不足分を補完する

## AI を組み込んだシステムの開発

自社サービスの機能そのものに LLM を組み込んでいます。英語圏のテックニュースを収集・要約して毎朝配信する「あさよむ テック」、位置情報の解決と分類を扱う「いこストック」がその実装例です。

## 使用しているモデル

| 用途 | モデル |
| --- | --- |
| 実装・エージェント実行（メイン） | Claude Code / Codex |
| レビュー・脆弱性検知（多モデル合議） | Grok / Gemini / Sakana Fugu |
| 画像・動画の解析 | Gemini |

同じ対象を複数のモデルに独立して検証させ、一致と不一致を突き合わせることで、単一モデルの盲点を減らす構成をとっています。

## 公開リポジトリ

- [**master-llm**](https://github.com/technobibi/master-llm) — ローカル LLM（LM Studio）と Claude を組み合わせたオーケストレーションを、「Claude 単体」と同一タスク・同一指示で比較する評価ハーネス。精度・クラウドコスト・実時間の 3 軸で計測し、HumanEval / MBPP の取り込みとルーティング学習データの生成まで行う
- [**OSSMate**](https://github.com/technobibi/OSSMate) — OSS のトレンドと Good First Issue を一覧化する Web アプリ（Go + React）
